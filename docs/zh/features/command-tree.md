# 命令树

命令树将构建命令的有向无环图以 ASCII 树的形式可视化，展示进程之间的父子关系及其执行的命令。

命令：`tree`

## 用法

```bash
catter tree [options] -- <build-command>
```

## 选项

| 选项                  | 说明                                                                           |
| --------------------- | ------------------------------------------------------------------------------ |
| `-d, --depth <n>`     | 限制渲染深度。                                                                 |
| `-a, --args <n>`      | 显示 `argv[0]` 之后的前 n 个参数。用 `-1` 保留全部。默认：`-1`。               |
| `-w, --arg-width <n>` | 将超过该长度的参数从中间截断到该长度，长度按字符（Unicode 码位）计。默认：10。 |

`tree` 也接受所有运行构建的命令共有的选项：`-C`、`--capture`、`--from` 和 handler 的选项（见[配置参考](../guide/configuration.md)）。

## 输出

输出为 ANSI 彩色的 ASCII 树，使用制表符（`│`、`├──`、`└──`）绘制。颜色按深度在 4 种颜色之间循环，便于快速区分嵌套层级。

典型的构建树可能如下所示：

```
make -j8
├── gcc -c main.c -o main.o
│   └── as -o main.o /tmp/cc1.s
├── gcc -c util.c -o util.o
│   └── as -o util.o /tmp/cc2.s
└── gcc main.o util.o -o app
    └── ld -o app main.o util.o -lc
```

每个节点显示进程的命令行，子节点为该进程派生的子进程。含 ASCII 空白（空格、Tab、换行符、垂直 Tab 或换页符）、引号或反斜杠的参数显示为 JSON 字符串；参数按 `--arg-width` 截断后，中间被截去的部分用 `....` 表示。树结构由实际的进程拦截构建而成，因此完全反映构建过程中的真实行为。

## 使用场景

- **理解构建编排** -- 查看构建系统如何调度编译器、汇编器和链接器。
- **调试异常进程派生** -- 识别构建中未预期的进程调用。
- **验证拦截完整性** -- 确认所有预期的编译操作都被 catter 正确拦截。
